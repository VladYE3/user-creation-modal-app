# User Creation Modal App

Реализация переиспользуемого модального окна с формой создания пользователя на Next.js, TypeScript, Tailwind CSS, shadcn/ui, react-hook-form + zod, с соблюдением FSD и настроенными инструментами качества кода (ESLint, Prettier, StyleLint, Husky, lint-staged, EditorConfig).

## Установка и запуск

```bash
npm install
npm run dev
```
